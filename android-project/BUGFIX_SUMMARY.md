## 二、详细修复内容

### 修复 1: Q1.5 假人分组阈值偏差 ⚠️✅

#### 问题描述

**修复前逻辑**:
```kotlin
val (group, dummyType) = when {
    maxHeight <= 60  -> "Q0"   to "Q0 假人（出生至 10 个月）"
    maxHeight <= 76  -> "Q0+"  to "Q0+ 假人（出生至 12 个月）"
    maxHeight <= 87  -> "Q1"   to "Q1 假人（9 个月至 18 个月）"
    maxHeight <= 100 -> "Q1.5" to "Q1.5 假人（12 个月至 36 个月）"  // ❌ 错误阈值
    maxHeight <= 125 -> "Q3"   to "Q3 假人（3 岁至 6 岁）"
    maxHeight <= 150 -> "Q6"   to "Q6 假人（6 岁至 10 岁）"
    else               -> "Q10"  to "Q10 假人（10 岁至 12 岁）"
}
```

**问题分析**:
- **修复前**: Q1.5 分组阈值为 `maxHeight <= 100`
- **实际标准**: ECE R129 Annex 19 定义 Q1.5 假人适用身高范围为 71-105 cm
- **影响**: 101-105 cm 的儿童会被错误地分配到 Q3 组，导致头枕高度和 Envelope 尺寸计算不准确

#### 修复方案

**修复后逻辑**:
```kotlin
val (group, dummyType) = when {
    maxHeight <= 60  -> "Q0"   to "Q0 假人（出生至 10 个月）"
    maxHeight <= 76  -> "Q0+"  to "Q0+ 假人（出生至 12 个月）"
    maxHeight <= 87  -> "Q1"   to "Q1 假人（9 个月至 18 个月）"
    maxHeight <= 105 -> "Q1.5" to "Q1.5 假人（12 个月至 36 个月）"  // ✅ 修正为 105
    maxHeight <= 125 -> "Q3"   to "Q3 假人（3 岁至 6 岁）"
    maxHeight <= 150 -> "Q6"   to "Q6 假人（6 岁至 10 岁）"
    else               -> "Q10"  to "Q10 假人（10 岁至 12 岁）"
}
```

### 修复 2: 体重换算精度不足 ⚠️✅

#### 问题描述

**修复前逻辑**:
```kotlin
weightRange = "根据身高转换：${(minHeight * 0.5).toInt()}kg - ${(maxHeight * 0.5).toInt()}kg"
```

**问题分析**:
- **修复前**: 使用简化的身高体重比（2:1）进行换算
- **实际标准**: ECE R129 Annex 19 定义了每个假人的精确体重范围
- **影响**: 简化换算可能导致测试要求不准确，不符合专业标准

**示例误差**:
| 身高 (cm) | 修复前体重 (kg) | 实际标准 (kg) | 误差 |
|----------|----------------|--------------|------|
| Q1 (87cm) | 40-43kg        | 9-18kg       | ❌ 严重误差 |
| Q3 (110cm)| 50-55kg        | 15-25kg      | ❌ 严重误差 |
| Q6 (135cm)| 62-67kg        | 22-36kg      | ❌ 严重误差 |

#### 修复方案

**第一步：新增精确体重范围函数**
```kotlin
/**
 * 根据假人分组获取精确的体重范围（严格按照 ECE R129 Annex 19）
 * 避免使用简化的身高*0.5换算，提高准确性
 */
private fun getWeightRangeByDummyType(group: String): String {
    return when {
        // Q0 和 Q0+ 假人：出生至约10-12个月
        group.contains("Q0") -> "0-13kg"

        // Q1 假人：9-18个月
        group == "Q1" -> "9-18kg"

        // Q1.5 假人：12-36个月
        group == "Q1.5" -> "9-18kg"

        // Q3 假人：3-6岁
        group == "Q3" -> "15-25kg"

        // Q6 假人：6-10岁
        group == "Q6" -> "22-36kg"

        // Q10 假人：10-12岁
        group == "Q10" -> "31-52kg"

        // 其他情况（FMVSS 213 等标准）
        else -> "根据假人类型确定"
    }
}
```

**第二步：修改体重换算逻辑**
```kotlin
// 基础适配数据
basicAdaptationData = BasicAdaptationData(
    dummyInfo = DummyInfo(
        dummyType = dummyType,
        heightRange = "${minHeight}cm - ${maxHeight}cm",
        weightRange = getWeightRangeByDummyType(group),  // ✅ 使用假人类型的精确体重范围
        installationDirection = installationDirection,
        ageGroup = getAgeGroupByHeight(maxHeight)
    )
)
```
