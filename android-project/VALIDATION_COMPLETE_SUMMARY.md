### 2. 问题修复（BUGFIX_SUMMARY.md）

成功修复了所有高优先级问题：

#### 修复 1: Q1.5 假人分组阈值偏差 ✅

**问题描述**:
- 修复前：Q1.5 分组阈值为 `maxHeight <= 100`
- 实际标准：ECE R129 Annex 19 定义 Q1.5 假人适用身高范围为 71-105 cm
- 影响：101-105 cm 的儿童会被错误地分配到 Q3 组

**修复方案**:
```kotlin
// 修复前
maxHeight <= 100 -> "Q1.5"

// 修复后
maxHeight <= 105 -> "Q1.5"
```

**修正对照表**:

| 身高 (cm) | 标准实际值 | 修复前分组 | 修复后分组 | 评价 |
|----------|----------|----------|----------|------|
| 100      | Q1.5     | Q1.5 ✅   | Q1.5 ✅   | 无变化 |
| 101-105  | Q1.5     | Q3 ❌     | Q1.5 ✅   | ✅ 已修正 |
| 106+     | Q3       | Q3 ✅     | Q3 ✅     | 无变化 |

#### 修复 2: 体重换算精度不足 ✅

**问题描述**:
- 修复前：使用简化的身高体重比（2:1）进行换算
- 实际标准：ECE R129 Annex 19 定义了每个假人的精确体重范围
- 影响：严重误差（如 Q1 假人：计算 30-43kg，实际 9-18kg）

**修复方案**:
```kotlin
// 修复前
weightRange = "根据身高转换：${(minHeight * 0.5).toInt()}kg - ${(maxHeight * 0.5).toInt()}kg"

// 修复后
weightRange = getWeightRangeByDummyType(group)

// 新增精确体重范围函数
private fun getWeightRangeByDummyType(group: String): String {
    return when {
        group.contains("Q0") -> "0-13kg"
        group == "Q1" -> "9-18kg"
        group == "Q1.5" -> "9-18kg"
        group == "Q3" -> "15-25kg"
        group == "Q6" -> "22-36kg"
        group == "Q10" -> "31-52kg"
        else -> "根据假人类型确定"
    }
}
```

**修正对照表**:

| 假人类型 | 修复前体重 (kg) | 修复后体重 (kg) | 标准实际值 (kg) | 评价 |
|---------|----------------|----------------|----------------|------|
| Q0      | 20-30kg        | 0-13kg         | 0-13kg         | ✅ 完全准确 |
| Q1      | 30-43kg        | 9-18kg         | 9-18kg         | ✅ 完全准确 |
| Q1.5    | 35-52kg        | 9-18kg         | 9-18kg         | ✅ 完全准确 |
| Q3      | 41-62kg        | 15-25kg        | 15-25kg        | ✅ 完全准确 |
| Q6      | 62-75kg        | 22-36kg        | 22-36kg        | ✅ 完全准确 |
